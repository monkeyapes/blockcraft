# Blockcraft native client

A Rust program with its own window and GPU renderer (wgpu + winit), replacing
the webview shell in `desktop/`. The goal is the same game, running natively.

## How it fits with the TypeScript game

- **Content comes from TypeScript.** `tools/export-native.ts` renders the
  texture atlas with the same recipes the web game uses and writes it, plus
  the block and item data (ids, names, textures, flags, shapes), into
  `native/assets/`. The native game loads those files, so art is drawn once.
  Re-run the export whenever blocks, items or textures change.
- **World generation is ported exactly** (`native/worldgen`), so a seed makes
  the same world in both, and a native client can join the existing server,
  which only ever sends edits.

## Layout

- `worldgen/` -- the world generator, a library with parity tests against
  chunks generated by `shared/src/terrain.ts`.
- `game/` -- the executable: window, renderer, meshing, player, UI.

## Phases

1. Core: window, renderer, meshing with the real block shapes, textures from
   the exported atlas, exact world generation, walking/flying, breaking and
   placing, true fullscreen.
2. Gameplay: lighting, inventory and crafting, saving, multiplayer.
3. Content: mobs, machines, combat, farming, the rest of the packs.

## Building

    cd native
    cargo run -p blockcraft-native --release
